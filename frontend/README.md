## 🔥 Aesthetic & Features

- 🌌 **Midnight Obsidian Cyber Palette**: Deep midnight dark mode with electric cyan, cyber indigo, and hyper violet glow accents.
- ⚡ **100vh Landing Page**: Fits hero banner, search, quick demo trial chips, tech stack badges, and footer inside a single 100vh desktop view.
- 📊 **5-Column Horizontal Cards**: Subject cards for Semester IV and III render in a clean 5-column grid layout.
- 📈 **Out-of-50 T4 Formatting**: Displays T4 Actual ($val \times 2 / 50$) and T4 Predicted out of 50.
- 🔄 **F5 Refresh Route Rehydration**: Seamless dynamic profile loading on route refresh without unmounting to search page.

## 💻 Quick Start

```powershell
# Navigate to frontend
cd frontend

# Install & run
npm install
npm run dev
```

App runs at: [http://localhost:5173/](http://localhost:5173/)
